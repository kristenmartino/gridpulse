1"""Rolling-origin evaluation and a single declared decision metric. 

2 

3Two problems this exists to fix, both self-inflicted and both documented. 

4 

5**1. One holdout window cannot rank anything.** The ARIMA order study 

6(`docs/ARIMA_ORDER_EXOG_STUDY.md`) ran a 168-hour holdout on 2026-07-28 and 

7again on 07-29 — the same code, a window one day apart. CAISO's verdict 

8**reversed sign** (−7.24 → +3.87 pts), WALC's +4.59 gain became +0.04, and 

9MISO's *control* error nearly halved (7.62 → 3.91) without anything changing. 

10A correct decision shipped on four numbers, one of which was noise. Every 

11future A/B inherits that variance unless the harness handles it. 

12 

13**2. Too many metrics decide things.** Serving decisions use mean MAPE 

14(`config.mape_grade`, the ADR-004 weights, the benchmark winner, the gate); 

15the A/B studies used sMAPE. Mixing them already produced a median-vs-mean 

16mix-up on a published page. So one metric decides — but *not* MAPE, and the 

17reason matters: 

18 

19**MAPE is asymmetric against over-forecasting.** For one hour, ``|A-F|/A`` 

20grows without bound as F exceeds A but caps at 100% as F approaches 0, so a 

21MAPE-minimising model is biased toward **under**-forecasting demand — the 

22expensive direction in grid operations, where under-procured reserves mean 

23scarcity risk. It also explodes on low denominators (SEC is a ~300 MW 

24co-op) and does not aggregate across BAs in any way that reflects total MW 

25error: 20% of SEC is 60 MW, 2% of PJM is ~2,000 MW. 

26 

27So this module follows the optimizing/satisficing split rather than pretending 

28one number can do every job: 

29 

30* **Optimizing — WAPE.** Scale-robust, no low-denominator blowup, aggregates 

31 to total MW error, peak hours dominate (correct for grid ops). Already 

32 computed in the benchmark payload. 

33* **Satisficing — bias band.** An arm cannot win by systematically 

34 under-forecasting; mean signed percentage error must stay inside 

35 ``MAX_ABS_BIAS_PCT``. This is precisely the guard MAPE lacks. 

36* **Satisficing — no MAPE regression** beyond ``MAX_MAPE_REGRESSION_PTS``. 

37 MAPE stays the *published* number, because comparability with EIA, the ISOs 

38 and every vendor scorecard is a real requirement — it just should not be the 

39 thing we optimise. 

40 

41Known cost: a WAPE-optimising experiment can disagree with the MAPE-based 

42serving gate. That gap is real and the fix is to migrate the gate, not to 

43optimise a worse metric because the gate happens to read it. 

44""" 

45

48import numpy as np

50#: The one metric an experiment is optimised on. WAPE, not MAPE — see the 

51#: module docstring for why MAPE's asymmetry points the wrong way for a grid. 

52DECISION_METRIC = "wape" 

53 

54#: Published for external comparability, and constrained rather than optimised. 

55REPORTED_METRIC = "mape" 

56 

57#: Satisficing: |mean signed percentage error| must stay inside this. Stops an 

58#: arm buying a WAPE win with a systematic under-forecast. 

59MAX_ABS_BIAS_PCT = 2.0 

60 

61#: Satisficing: the published metric may not degrade by more than this, however 

62#: good the optimising metric looks. 

63MAX_MAPE_REGRESSION_PTS = 0.5 

64 

65#: An arm must win in at least this fraction of windows. Guards against a 

66#: single catastrophic window driving the mean: the fleet ARIMA run had one BA 

67#: at −19.18 against a typical −0.2, which is a tail-risk finding, not evidence 

68#: that the average window favours either arm. Both facts matter and they are 

69#: different facts. 

70MIN_SIGN_CONSISTENCY = 0.75 

71 

72#: |mean| must exceed this many standard errors. 2.0 ≈ the conventional 95% 

73#: paired threshold; with the window counts realistic here (8–12) this is 

74#: deliberately a rule of thumb, not an exact test — see `verdict`. 

75MIN_T_STATISTIC = 2.0 

76 

77#: Below this, `verdict` refuses to call anything. One window is what produced 

78#: the CAISO reversal; two cannot distinguish a trend from a coin flip. 

79MIN_WINDOWS_FOR_A_VERDICT = 4

82def rolling_origin_splits( 

83 n_rows: int, 

84 *, 

85 n_windows: int, 

86 holdout_h: int, 

87 stride_h: int | None = None, 

88 min_train_h: int, 

89) -> list[tuple[slice, slice]]: 

90 """Walk-forward (train, test) index slices, newest window first. 

91 

92 Each window holds out ``holdout_h`` rows and trains on everything before 

93 them — never after, so no window can see its own future. Windows step back 

94 by ``stride_h`` (default: ``holdout_h``, i.e. adjacent non-overlapping 

95 holdouts). 

96 

97 Returns fewer than ``n_windows`` splits — possibly zero — when history runs 

98 out. That is deliberate: a caller that silently accepted a short list would 

99 reproduce the failure mode this module exists to prevent, so callers should 

100 check ``len()`` and say what they got. 

101 

102 Args: 

103 n_rows: Rows available, after feature engineering has dropped its warmup. 

104 n_windows: Maximum number of windows to produce. 

105 holdout_h: Rows held out per window. 

106 stride_h: Rows between consecutive window origins. Defaults to 

107 ``holdout_h`` (non-overlapping holdouts). 

108 min_train_h: A window is dropped if its train slice is shorter than this. 

109 

110 Returns: 

111 ``[(train_slice, test_slice), ...]``, most recent window first. 

112 """ 

113 if holdout_h <= 0 or n_windows <= 0: 

114 return [] 

115 step = holdout_h if stride_h is None else stride_h 

116 if step <= 0: 

117 return [] 

118 

119 splits: list[tuple[slice, slice]] = [] 

120 for k in range(n_windows): 

121 test_end = n_rows - k * step 

122 test_start = test_end - holdout_h 

123 if test_start < min_train_h: 

124 break 

125 splits.append((slice(0, test_start), slice(test_start, test_end))) 

126 return splits

129def paired_deltas( 

130 control: list[float] | np.ndarray, treatment: list[float] | np.ndarray 

131) -> np.ndarray: 

132 """Per-window ``control - treatment`` for an error metric. 

133 

134 Positive means the treatment is **better** (lower error), matching the 

135 ``delta_*`` convention already used by the benchmark payload. Windows where 

136 either arm failed to score (``None``/NaN) are dropped pairwise, so one 

137 arm's blow-up cannot silently shorten only its own series. 

138 """ 

139 a = np.asarray(control, dtype=float) 

140 b = np.asarray(treatment, dtype=float) 

141 if a.shape != b.shape: 

142 raise ValueError(f"paired arms must be the same length: {a.shape} vs {b.shape}") 

143 ok = np.isfinite(a) & np.isfinite(b) 

144 return a[ok] - b[ok]

147def wape(actual: np.ndarray, predicted: np.ndarray) -> float: 

148 """``sum|error| / sum|actual|`` as a percentage — the optimising metric. 

149 

150 Unlike MAPE this is a ratio of totals, so a low-demand hour cannot 

151 dominate, and summing across BAs stays meaningful (it is MW error 

152 normalised by MW served). 

153 """ 

154 a = np.asarray(actual, dtype=float) 

155 f = np.asarray(predicted, dtype=float) 

156 ok = np.isfinite(a) & np.isfinite(f) 

157 denom = np.abs(a[ok]).sum() 

158 if denom == 0: 

159 return float("nan") 

160 return float(np.abs(a[ok] - f[ok]).sum() / denom * 100) 

161

163def bias_pct(actual: np.ndarray, predicted: np.ndarray) -> float: 

164 """Mean **signed** percentage error: ``mean((F - A) / A)`` as a percent. 

165 

166 Negative means the forecast runs low. This is the number the satisficing 

167 constraint watches, because the optimising metric is blind to direction 

168 and under-forecasting demand is the operationally expensive error. 

169 """ 

170 a = np.asarray(actual, dtype=float) 

171 f = np.asarray(predicted, dtype=float) 

172 ok = np.isfinite(a) & np.isfinite(f) & (a != 0) 

173 if not ok.any(): 

174 return float("nan") 

175 return float(np.mean((f[ok] - a[ok]) / a[ok]) * 100)

178def satisficing_check( 

179 *, 

180 treatment_bias_pct: float | None, 

181 control_mape: float | None, 

182 treatment_mape: float | None, 

183 max_abs_bias_pct: float = MAX_ABS_BIAS_PCT, 

184 max_mape_regression_pts: float = MAX_MAPE_REGRESSION_PTS, 

185) -> dict: 

186 """Do the constraints hold? A failure vetoes a win on the optimising metric. 

187 

188 Returns ``{"passed": bool, "failures": [str, ...]}``. Unmeasurable inputs 

189 (``None``/NaN) are reported as failures rather than passes — an unchecked 

190 constraint is not a satisfied one. 

191 """ 

192 failures: list[str] = [] 

193 

194 if treatment_bias_pct is None or not np.isfinite(treatment_bias_pct): 

195 failures.append("bias not measured") 

196 elif abs(treatment_bias_pct) > max_abs_bias_pct: 

197 direction = "under" if treatment_bias_pct < 0 else "over" 

198 failures.append( 

199 f"bias {treatment_bias_pct:+.2f}% exceeds ±{max_abs_bias_pct}% " 

200 f"({direction}-forecasting systematically)" 

201 ) 

202 

203 if ( 

204 control_mape is None 

205 or treatment_mape is None 

206 or not np.isfinite(control_mape) 

207 or not np.isfinite(treatment_mape) 

208 ): 

209 failures.append("published metric (MAPE) not measured") 

210 else: 

211 regression = treatment_mape - control_mape 

212 if regression > max_mape_regression_pts: 

213 failures.append( 

214 f"published MAPE regresses {regression:+.2f} pts " 

215 f"(> {max_mape_regression_pts} allowed)" 

216 ) 

217 

218 return {"passed": not failures, "failures": failures}

221def verdict( 

222 deltas: list[float] | np.ndarray, 

223 *, 

224 min_sign_consistency: float = MIN_SIGN_CONSISTENCY, 

225 min_t: float = MIN_T_STATISTIC, 

226 min_windows: int = MIN_WINDOWS_FOR_A_VERDICT, 

227) -> dict: 

228 """Decide whether a paired A/B difference is real, or refuse to decide. 

229 

230 Two conditions, both required, because they catch different failures: 

231 

232 * **Magnitude** — ``|mean| >= min_t * stderr``. Rejects differences 

233 indistinguishable from window-to-window noise. This alone would have 

234 failed CAISO, whose two observed deltas were −7.24 and +3.87. 

235 * **Sign consistency** — the winning arm must win in at least 

236 ``min_sign_consistency`` of windows. Rejects a mean driven by one 

237 catastrophic window, which is a *tail-risk* finding and deserves to be 

238 reported as one rather than laundered into an average. 

239 

240 Fewer than ``min_windows`` windows is always ``inconclusive``, whatever the 

241 numbers look like. 

242 

243 The t-statistic here is a decision rule, not a significance claim: windows 

244 from a rolling origin overlap in training data and are not independent 

245 draws, so the nominal p-value would be optimistic. It is used as a 

246 conservative filter, and `worst_window` is reported alongside precisely 

247 because a passing mean is not the whole story. 

248 

249 Returns: 

250 ``{"decisive", "winner", "n", "mean", "median", "stderr", "t", 

251 "sign_consistency", "worst_window", "best_window", "reason"}`` — 

252 ``winner`` is ``"treatment"``, ``"control"``, or ``None``. 

253 """ 

254 d = np.asarray([x for x in np.asarray(deltas, dtype=float) if np.isfinite(x)], dtype=float) 

255 n = int(d.size) 

256 out: dict = { 

257 "decisive": False, 

258 "winner": None, 

259 "n": n, 

260 "mean": None, 

261 "median": None, 

262 "stderr": None, 

263 "t": None, 

264 "sign_consistency": None, 

265 "worst_window": None, 

266 "best_window": None, 

267 "reason": "", 

268 } 

269 if n == 0: 

270 out["reason"] = "no scored windows" 

271 return out 

272 

273 mean = float(d.mean()) 

274 out.update( 

275 mean=round(mean, 4), 

276 median=round(float(np.median(d)), 4), 

277 worst_window=round(float(d.min()), 4), 

278 best_window=round(float(d.max()), 4), 

279 ) 

280 if n < min_windows: 

281 out["reason"] = f"{n} window(s) < {min_windows} required for a verdict" 

282 return out 

283 

284 # ddof=1: we are estimating the spread of window outcomes, not describing 

285 # these particular windows. 

286 stderr = float(d.std(ddof=1) / np.sqrt(n)) 

287 out["stderr"] = round(stderr, 4) 

288 

289 if stderr == 0: 

290 # Identical deltas in every window — a real effect (often an exact 

291 # no-op, delta 0) with no spread to test against. 

292 out["t"] = None 

293 consistency = 1.0 if mean != 0 else 0.0 

294 else: 

295 out["t"] = round(mean / stderr, 3) 

296 favoured = np.sign(mean) 

297 consistency = float((np.sign(d) == favoured).sum() / n) 

298 out["sign_consistency"] = round(consistency, 3) 

299 

300 if mean == 0: 

301 out["reason"] = "no difference" 

302 return out 

303 

304 # Outlier domination has its own signature: the mean points one way and 

305 # the MEDIAN points the other. One catastrophic window can drag a mean 

306 # across zero while most windows disagree with it. Checked before the 

307 # noise test because that test would also reject this input — such an 

308 # outlier inflates the variance it is measured against — but "within 

309 # noise" is the less useful thing to tell a reader. This is the ISONE 

310 # shape: three small wins and one -19.18. 

311 median = float(np.median(d)) 

312 if median != 0 and np.sign(mean) != np.sign(median): 

313 out["reason"] = ( 

314 f"mean {mean:+.3f} and median {median:+.3f} disagree in sign — " 

315 f"outlier window(s) dominate; report as tail risk, not as a win" 

316 ) 

317 return out 

318 

319 if stderr > 0 and abs(mean) < min_t * stderr: 

320 out["reason"] = ( 

321 f"|mean| {abs(mean):.3f} < {min_t}x stderr {stderr:.3f} — within window-to-window noise" 

322 ) 

323 return out 

324 if consistency < min_sign_consistency: 

325 out["reason"] = ( 

326 f"wins only {consistency:.0%} of windows (< {min_sign_consistency:.0%} required) — " 

327 f"real on average but not reliable enough to ship" 

328 ) 

329 return out 

330 

331 out["decisive"] = True 

332 out["winner"] = "treatment" if mean > 0 else "control" 

333 # `stderr` is 0 when every window produced the identical delta. The branch 

334 # above already handles that for `t`; this string divided by it anyway and 

335 # raised ZeroDivisionError, so a treatment that improved every window by 

336 # exactly the same amount crashed the verdict instead of winning it. 

337 spread = ( 

338 f" ({abs(mean) / stderr:.1f}x stderr)" if stderr > 0 else " (identical in every window)" 

339 ) 

340 out["reason"] = ( 

341 f"{out['winner']} wins {consistency:.0%} of {n} windows, mean {mean:+.3f} pts{spread}" 

342 ) 

343 return out
