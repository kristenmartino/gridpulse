1"""Demand-reading plausibility — is EIA's number a measurement or an artifact? 

2 

3Promoted from ``components/_callbacks_us_grid.py`` (#225), where it guarded only 

4the US-Grid stress surfaces and ``/api/v1/grid/summary``. The 2026-07 vintage 

5study (#309/#312) showed the same artifacts reaching two unguarded consumers: 

6 

7* **The forecast anchor** — ``demand_lag_1h`` and 20 sibling autoregressive 

8 features seed from the newest reading (``feature_engineering.py:220``), so a 

9 partial poisons every recursive forecast hour. 

10* **The region-page tiles** — LADWP rendered NOW 730 MW / trend −80.6% / 

11 "demand is 78.1% below average" from a partial that settled to ~3,034 an 

12 hour later. 

13 

14## What EIA actually publishes (measured 2026-07-15/16, Form EIA-930 grounded) 

15 

16The newest hour's ``D`` value cycles **stub → partial → settled**: the row is 

17born mid-hour carrying the BA's own day-ahead forecast (``D == DF`` exactly), 

18a first estimate replaces it ~2-6 min after the hour closes, and the same-day 

19deadline value lands by ~+50 min. Form EIA-930 *mandates* this: same-day files 

20are due within 60 minutes and respondents are told to "submit their best 

21estimates on schedule and correct the data with a resubmission within 3 days." 

22Partials are required behavior, not a bug — the guard's job is to keep the 

23gross ones out of anchors and KPIs, with disclosure. 

24 

25## Signal design — every threshold traces to a measured case 

26 

27Three independent signals (any fires ⇒ artifact): 

28 

291. **Near-zero glitch** — below 10% of the trailing-24h median (#142's 

30 region-relative rule; catches TIDC-class zeros that survive upstream 

31 coercion in aggregate lists). 

322. **Single-step collapse** — a >60% one-hour drop that ALSO lands below 60% 

33 of the median (both required, so a return-from-spike is not flagged). 

34 Catches LDWP 3,464→730 (−79%, 22% of median) and the #225 "APS −90.7%". 

353. **Day-ahead ratio** (new, #309) — below 50% of the BA's own day-ahead 

36 forecast (``DF``), **low side only**. Load-bearing for stuck partials that 

37 evade signals 1-2: IID frozen at 339 for 6+ hours (34% of median — above 

38 signal 1; no step — signal 2 blind; 33% of DF ⇒ caught), AZPS frozen at 

39 1959 (26% of DF). Deliberate non-fires, measured: the ``D == DF`` 

40 placeholder stub gives ratio exactly 1.0 (and the stub is a GOOD anchor — 

41 fleet mean ~2.7% error; removing it measured WORSE, 6.55%→7.72%); PSCO 

42 legitimately runs 118-121% of its own day-ahead, which is why there is no 

43 high-side test — a symmetric band would false-flag real demand. BPAT's 

44 +20% high partial is therefore deliberately uncatchable: the accepted, 

45 documented residual. 

46 

47## Scope rule for series coercion 

48 

49``coerce_demand_artifacts`` judges only the **trailing hours** of a frame. 

50Measured: gross artifacts live only at the tail — EIA revisions settle older 

51hours in every fresh fetch — while bulk-revision regions' same-day values are 

52provisional-but-plausible (14-40% off, revised at the next-morning daily file) 

53and must NOT be excluded; that is provenance-callout territory, not artifact 

54territory. 

55"""

71#: How many trailing hours of a demand frame are candidates for exclusion. 

72#: Measured settle behavior: stub→partial→settled completes within ~1h for 

73#: most BAs; the worst observed partial (LDWP) held ~44 min, and AZPS held a 

74#: partial for ~46 min. Six hours covers every observed case with margin 

75#: while structurally exempting the settled bulk of the series. 

76DEMAND_ARTIFACT_TRAILING_HOURS = 6

79def is_real_positive(value: Any) -> bool: 

80 """Strict guard for downstream arithmetic: True only when ``value`` is 

81 a finite (non-NaN, non-inf) strictly positive number. 

82 

83 Rejects strings outright (no silent coercion) and normalizes numpy 

84 bool returns to Python ``bool`` so callers can use ``is True / is False``. 

85 """ 

86 if value is None or isinstance(value, (str, bytes)): 

87 return False 

88 try: 

89 f = float(value) 

90 except (TypeError, ValueError): 

91 return False 

92 return bool(np.isfinite(f) and f > 0)

95def is_implausible_demand_artifact( 

96 current_mw: float, 

97 today_mw: list, 

98 prev_mw: float | None = None, 

99 day_ahead_mw: float | None = None, 

100) -> bool: 

101 """Check if a BA's demand reading is an implausible artifact. 

102 

103 See the module docstring for the three signals and the measured cases 

104 behind every threshold. ``day_ahead_mw`` (EIA's ``DF`` for the same hour) 

105 enables signal 3; when absent or non-finite that signal is skipped — the 

106 guard degrades to the original #225 pair. 

107 

108 Args: 

109 current_mw: The reading under judgment, MW. 

110 today_mw: Trailing ~24h demand list (may contain NaN / zero). 

111 prev_mw: The previous real reading, MW — enables the step-collapse 

112 signal. Optional; when absent only signals (1) and (3) apply. 

113 day_ahead_mw: The BA's own day-ahead forecast for the same hour. 

114 

115 Returns: 

116 True if ``current_mw`` should be excluded from anchors and KPIs. 

117 """ 

118 if not is_real_positive(current_mw): 

119 return True # Already filtered out by is_real_positive, but be explicit 

120 

121 if not today_mw: 

122 return False # No history available; assume current is real 

123 

124 positive_history = [float(v) for v in today_mw if is_real_positive(v)] 

125 if not positive_history: 

126 return False # All history is suspect; can't establish scale, assume current is real 

127 

128 median_24h = float(np.median(positive_history)) 

129 if median_24h <= 0: 

130 return False # Degenerate history; can't establish scale, assume current is real 

131 

132 # (3) day-ahead ratio, PAIRED with a below-normal-scale co-signal (the 

133 # same design as signal 2): some BAs' own day-ahead forecasts are badly 

134 # high (PSEI's mean DF error is 47%), so a bare ratio would false-flag a 

135 # real deep trough under a bad forecast. A stuck partial is far below the 

136 # median too; a real reading under a bad DF usually is not. 

137 if ( 

138 is_real_positive(day_ahead_mw) 

139 and current_mw < DEMAND_ARTIFACT_DAY_AHEAD_FRACTION * float(day_ahead_mw) 

140 and current_mw < DEMAND_ARTIFACT_STEP_LOW_FRACTION * median_24h 

141 ): 

142 return True 

143 

144 # (1) near-zero glitch 

145 if current_mw < DEMAND_ARTIFACT_NEAR_ZERO_FRACTION * median_24h: 

146 return True 

147 # (2) single-step collapse (needs a prior real reading) 

148 return bool( 

149 is_real_positive(prev_mw) 

150 and current_mw < DEMAND_ARTIFACT_STEP_DROP_FRACTION * float(prev_mw) 

151 and current_mw < DEMAND_ARTIFACT_STEP_LOW_FRACTION * median_24h 

152 )

155def coerce_demand_artifacts( 

156 demand_df: pd.DataFrame | None, 

157 *, 

158 trailing_hours: int = DEMAND_ARTIFACT_TRAILING_HOURS, 

159) -> tuple[pd.DataFrame | None, list[dict[str, Any]]]: 

160 """NaN-coerce implausible readings in a demand frame's trailing hours. 

161 

162 Returns ``(cleaned_frame, exclusions)`` where ``cleaned_frame`` is a copy 

163 (the input is never mutated — the vintage study must keep seeing the raw 

164 values) and ``exclusions`` is ``[{"ts", "mw", "reason"}]`` for disclosure 

165 on the tiles, the operating summary, and ``/grid/summary``. 

166 

167 Only the trailing ``trailing_hours`` rows are judged (module docstring: 

168 artifacts live at the tail). Each candidate row is judged against its OWN 

169 trailing-24h median and its own prior real reading, so a run of stuck 

170 partials is caught row by row. Rows already NaN are skipped — they are 

171 absences, not artifacts. Degrades gracefully when ``forecast_mw`` is 

172 absent (GCS-fallback frames carry it, but never assume). 

173 """ 

174 if demand_df is None or len(demand_df) == 0 or "demand_mw" not in demand_df.columns: 

175 return demand_df, [] 

176 

177 cleaned = demand_df.copy() 

178 values = pd.to_numeric(cleaned["demand_mw"], errors="coerce") 

179 day_ahead = ( 

180 pd.to_numeric(cleaned["forecast_mw"], errors="coerce") 

181 if "forecast_mw" in cleaned.columns 

182 else None 

183 ) 

184 

185 n = len(cleaned) 

186 start = max(0, n - trailing_hours) 

187 exclusions: list[dict[str, Any]] = [] 

188 

189 for i in range(start, n): 

190 current = values.iloc[i] 

191 if not is_real_positive(current): 

192 continue # an absence, not an artifact 

193 

194 history = [v for v in values.iloc[max(0, i - 24) : i].tolist() if is_real_positive(v)] 

195 prev = history[-1] if history else None 

196 df_mw = float(day_ahead.iloc[i]) if day_ahead is not None else None 

197 

198 if not is_implausible_demand_artifact( 

199 float(current), history, prev_mw=prev, day_ahead_mw=df_mw 

200 ): 

201 continue 

202 

203 # Name the reason for the disclosure surfaces — mirror the signal order. 

204 median_24h = float(np.median(history)) if history else float("nan") 

205 if ( 

206 df_mw is not None 

207 and is_real_positive(df_mw) 

208 and float(current) < (DEMAND_ARTIFACT_DAY_AHEAD_FRACTION * df_mw) 

209 ): 

210 reason = f"{float(current) / df_mw:.0%} of the BA's own day-ahead forecast" 

211 elif np.isfinite(median_24h) and float(current) < ( 

212 DEMAND_ARTIFACT_NEAR_ZERO_FRACTION * median_24h 

213 ): 

214 reason = f"near-zero vs 24h median ({float(current) / median_24h:.0%})" 

215 else: 

216 drop = (1 - float(current) / float(prev)) if prev else float("nan") 

217 reason = f"{drop:.0%} single-hour drop to {float(current) / median_24h:.0%} of the daily median" 

218 

219 ts = cleaned["timestamp"].iloc[i] if "timestamp" in cleaned.columns else None 

220 exclusions.append( 

221 { 

222 "ts": ts.isoformat() if hasattr(ts, "isoformat") else str(ts), 

223 "mw": round(float(current), 2), 

224 "reason": reason, 

225 } 

226 ) 

227 cleaned.iloc[i, cleaned.columns.get_loc("demand_mw")] = np.nan 

228 values.iloc[i] = np.nan # later rows must not use an excluded value as prev/history 

229 

230 return cleaned, exclusions
